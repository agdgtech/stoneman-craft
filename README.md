# Stoneman Craft — Crafted By Hand

Single-file, responsive multi-page business website for **Stoneman Craft** (artisan bakery & handcrafted homeware, Portland, OR).

- `index.html` is the whole app: HTML5 + Tailwind CSS (CDN) + vanilla JavaScript + Font Awesome.
- Pages (hash-routed, no reload): Home, About, Products, Services, Gallery, Contact.
- Enquiry / quote modal, gallery lightbox (keyboard + swipe), toasts, mobile nav drawer.
- **Live Customizer** (bottom-left button): edit company text, contact details and hours, change the brand colour or pick a preset, toggle home sections, add/delete products. Changes are saved in the browser's localStorage.

Open `index.html` directly in a browser, or visit the GitHub Pages site.

> Forms show a confirmation toast only — connect them to a form service (e.g. Formspree) or backend to receive real submissions.
